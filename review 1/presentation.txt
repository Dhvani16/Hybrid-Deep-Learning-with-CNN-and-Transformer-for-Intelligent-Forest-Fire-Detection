SECTION 2 — CONCEPT EXPLANATIONS (what to say when asked)
----------------------------------------------------------------

► WHAT IS A CNN (Convolutional Neural Network)?
  A CNN is a type of neural network designed for image data. It uses small
  filters (kernels) that slide across the image to detect local patterns —
  edges, textures, colours. Each layer builds on the previous one, going from
  low-level features (edges) to high-level features (flame shapes, smoke).
  The key property: it looks at small local regions at a time.

► WHAT IS A TRANSFORMER (in vision)?
  Originally designed for text (NLP), a Transformer splits the input into
  patches and uses Self-Attention to find relationships between ALL patches
  simultaneously — not just neighbours. This is called global context.
  For an image, this means the model can connect a faint smoke patch in the
  top-left corner with a flame patch in the bottom-right — something a CNN
  cannot do directly.

► WHAT IS SELF-ATTENTION?
  Self-Attention is the core mechanism of a Transformer. For every patch in
  the image, it computes a score (attention weight) with every other patch.
  High attention weight = "these two regions are related." This allows the
  model to attend to the most relevant parts of the image for the prediction.

► WHAT IS MULTI-HEAD ATTENTION?
  Instead of computing one set of attention scores, Multi-Head Attention runs
  several attention computations in parallel (called heads). Each head learns
  to attend to different aspects — one head might focus on colour, another on
  shape, another on spatial relationships. Their outputs are concatenated.
  We use 8 heads in our Transformer encoder.

► WHAT IS EfficientNet-B4?
  EfficientNet (Tan & Le, 2019) is a CNN family that scales three dimensions
  simultaneously: depth (more layers), width (more filters per layer), and
  resolution (input image size). B4 is the 4th scale level. It gives the best
  accuracy-to-efficiency ratio among CNNs and is pretrained on ImageNet-1K.
  It extracts a feature map of shape 7×7×1792 from a 224×224 input image.

► WHAT IS ViT-B/16?
  Vision Transformer Base model with 16×16 pixel patches. A 224×224 image
  is split into 196 non-overlapping patches (14×14 grid). Each patch is
  linearly projected into an embedding vector. A CLS token is prepended and
  the sequence goes through 12 Transformer encoder layers. The CLS token
  output is used for classification. Pretrained on ImageNet-21K.

► WHAT IS THE HYBRID MODEL (our proposed model)?
  It combines EfficientNet-B4 (CNN) as a backbone to extract local spatial
  features, then feeds those features into a 4-layer Transformer encoder to
  reason about global context. The key idea: instead of raw patches, we give
  the Transformer rich CNN features — so it needs far fewer layers to work.
  Final classification is done using the CLS token's output vector.

► WHY USE A HYBRID INSTEAD OF JUST CNN OR ViT?
  CNNs are strong on local patterns but cannot model long-range dependencies.
  ViTs model global context but need very large datasets to train from scratch.
  A hybrid gets the best of both: local feature extraction from CNN + global
  reasoning from Transformer, while being more data-efficient than a pure ViT.

► WHAT IS TWO-PHASE TRAINING?
  Phase 1: The CNN backbone is frozen (weights don't change). Only the new
  Transformer + classifier layers are trained. This lets the new layers
  stabilise without disrupting pretrained CNN features (8 epochs, lr=5e-4).
  Phase 2: All layers are unfrozen and the whole network is fine-tuned
  end-to-end, but with a smaller learning rate on the CNN backbone (1e-5)
  to avoid overwriting useful pretrained features (20 epochs).
  The CNN backbone gets lr=1e-5; Transformer + head gets lr=1e-4.

► WHAT IS GRAD-CAM?
  Gradient-weighted Class Activation Mapping. It uses the gradients of the
  predicted class with respect to the last convolutional layer's feature maps
  to produce a heatmap showing which spatial regions influenced the prediction.
  A bright region = the model focused there when making its decision.
  Used for interpretability — to verify the CNN is looking at fire/smoke,
  not irrelevant background pixels.

► WHAT IS A TRANSFORMER ATTENTION MAP?
  At each Transformer layer, the CLS token's attention weights over all 49
  spatial patches are extracted. High weight = the model considers that patch
  important for the final prediction. Visualised by reshaping the 49 weights
  back into a 7×7 spatial grid and overlaying on the original image.

► WHAT IS STRATIFIED SPLIT?
  When splitting data into train/val/test, a stratified split ensures the
  class proportions are the same in all three sets. Without this, you might
  accidentally put all no-fire images in the test set. We use 70/15/15 split.
  Dataset: 755 fire + 244 no-fire = 999 total images.
  Train=698, Val=149, Test=152.

► WHAT IS CLASS-WEIGHTED LOSS?
  Our dataset has 3.09× more fire images than no-fire images. A standard loss
  function would bias the model to always predict "fire." Class-weighted
  cross-entropy assigns higher loss penalty to mistakes on the minority class
  (no-fire), forcing the model to learn both classes equally well.

► WHAT IS AUC-ROC?
  The ROC curve plots True Positive Rate (Recall) vs. False Positive Rate at
  every classification threshold. AUC (Area Under this Curve) summarises the
  model's ability to distinguish between classes across all thresholds.
  AUC = 1.0 means perfect separation; AUC = 0.5 means random guessing.
  Our models: CNN=0.9977, ViT=0.9998, Hybrid=0.9965 — all excellent.

► WHAT IS PRECISION vs RECALL?
  Precision = of all fire predictions, how many were actually fire?
             High precision → few false alarms.
  Recall    = of all actual fires, how many did we detect?
             High recall → few missed fires.
  In fire detection, RECALL is more critical. Missing a fire is far more
  dangerous than a false alarm. ViT achieved Recall = 100% (zero missed fires).

► WHAT IS F1-SCORE?
  F1 = 2 × (Precision × Recall) / (Precision + Recall)
  It is the harmonic mean of Precision and Recall. Used when you want a single
  metric that balances both, especially with class imbalance.

SECTION 3 — KEY NUMBERS TO MEMORISE
----------------------------------------------------------------

Dataset
  Total images      : 999  (755 fire + 244 no-fire)
  Class imbalance   : 3.09:1  (fire:no-fire)
  Train / Val / Test: 698 / 149 / 152  (70% / 15% / 15%)
  Input size        : 224×224 RGB

Model Architecture (Hybrid)
  CNN output feature map : 7×7×1792
  After 1×1 Conv proj    : 7×7×512
  Patch tokens           : 49  (7×7 flattened)
  Transformer layers     : 4
  Attention heads        : 8
  Embedding dimension    : 512
  Dropout                : 0.3

Training
  Phase 1 : 8 epochs,  lr = 5×10⁻⁴  (Transformer + head only)
  Phase 2 : 20 epochs, CNN lr = 1×10⁻⁵, Transformer lr = 1×10⁻⁴
  Optimizer   : AdamW
  Scheduler   : CosineAnnealingLR
  Batch size  : 32
  Hardware    : NVIDIA T4 GPU (Google Colab)

Results (Test Set — 152 images)
  CNN (EfficientNet-B4) : Accuracy=98.68%  Recall=99.12%  F1=0.9912  AUC=0.9977
  ViT-B/16              : Accuracy=99.34%  Recall=100%    F1=0.9956  AUC=0.9998
  Hybrid (Ours)         : Accuracy=95.39%  Recall=95.61%  F1=0.9689  AUC=0.9965

  Describe the 3-stage pipeline: "The input image passes through EfficientNet-B4,

SECTION 5 — EXPECTED QUESTIONS & ANSWERS
----------------------------------------------------------------

Q1: Why did you choose EfficientNet-B4 specifically?
A:  EfficientNet uses compound scaling — it scales depth, width, and resolution
    together rather than independently. B4 is the optimal balance between
    accuracy and computational cost. De Venâncio et al. (2022) showed it
    outperforms ResNet and VGG on aerial fire image classification specifically.

Q2: Why 4 Transformer layers? Why not more?
A:  Our dataset has only 999 images. More Transformer layers = more parameters =
    higher risk of overfitting on small data. 4 layers gives sufficient depth
    for global reasoning without overfitting. Larger datasets would justify more.

Q3: Why is the CNN backbone frozen in Phase 1?
A:  EfficientNet-B4 is pretrained on ImageNet with millions of images. If we
    train all layers from the start, the random initialisation of the Transformer
    will produce large gradients that corrupt the pretrained CNN weights before
    the Transformer has a chance to stabilise. Phase 1 protects those weights.

Q4: What is the CLS token and why is it important?
A:  CLS (Classification) token is a learnable embedding that doesn't correspond
    to any image patch. Through self-attention, it attends to all 49 patch tokens
    and aggregates global information. After Transformer processing, only the CLS
    token is passed to the classifier. It acts as a summary of the entire image.

Q5: How did you handle class imbalance?
A:  The dataset has 755 fire and 244 no-fire images — a 3.09:1 ratio. We used
    class-weighted cross-entropy loss where the no-fire class gets a higher
    penalty on mistakes, proportional to its rarity. This stops the model from
    ignoring the minority class.

Q6: Why is Recall more important than Precision for fire detection?
A:  A false negative (missed fire) means a real fire is not reported — it can
    spread and cause catastrophic damage. A false positive (false alarm) means
    an unnecessary response dispatch — costly but manageable. Therefore we
    optimise for high recall — we would rather raise a false alarm than miss a
    real fire.

Q7: What is Grad-CAM and how does it prove model correctness?
A:  Grad-CAM produces a heatmap showing which pixels the CNN focused on.
    If it highlights flame textures and smoke regions rather than trees or sky,
    we can trust the model is making decisions based on relevant visual evidence,
    not spurious correlations. It is a form of explainability/interpretability.

Q8: Why did you use a 70/15/15 split instead of 80/10/10?
A:  With 999 total images, a 15% validation set gives 149 images and a 15% test
    set gives 152 images — enough for statistically reliable evaluation. 80/10/10
    would give only ~100 images per evaluation set which increases variance in
    metrics. Stratification ensures class ratios are preserved in each split.

Q9: What is the difference between validation set and test set?
A:  Validation set is used during training to tune hyperparameters (learning rate,
    number of epochs, etc.) and select the best model checkpoint. Test set is
    held out completely and only used once — for final performance reporting.
    Using the test set for any tuning decisions would be data leakage.

Q10: What is AdamW and why use it over regular Adam?
A:  AdamW is Adam with decoupled weight decay regularisation. Regular Adam
    incorrectly applies L2 regularisation through the gradient update, which
    interacts poorly with adaptive learning rates. AdamW fixes this and gives
    better generalisation, especially for Transformer models.

Q11: What is CosineAnnealingLR?
A:  It is a learning rate scheduler that decreases the learning rate following a
    cosine curve — starting high, decreasing smoothly, reaching near-zero at the
    end of training. This allows large steps early (fast learning) and small steps
    late (fine-grained convergence), avoiding overshooting the optimum.

Q12: What is Albumentations used for?
A:  It is a Python library for image augmentation — applying random transformations
    to training images: horizontal flip, rotation, brightness/contrast change,
    fog simulation, random crop. This artificially increases dataset diversity and
    reduces overfitting without collecting more data.

Q13: What is the difference between CoAtNet and your hybrid model?
A:  CoAtNet integrates convolution directly inside the Transformer layers using
    depthwise convolutions within the attention mechanism. Our approach is simpler
    and more modular: a standalone CNN backbone feeds its output into a standalone
    Transformer encoder. Our design is easier to train on small datasets and
    allows independent pretraining of each component.

Q14: What are the limitations of this study?
A:  The main limitation is the small dataset size — 999 images. Hybrid models
    typically show their advantage at 10,000+ images. The dataset is also binary
    (fire / no-fire) — real deployment needs multi-class (fire, smoke, smouldering).
    The study uses offline inference; real-time video stream integration is future work.

Q15: What does "end-to-end trainable" mean?
A:  All layers — CNN backbone, Transformer encoder, and classifier head — are
    trained together in a single training loop. Gradients flow from the loss all
    the way back through every layer. This allows the CNN and Transformer to adapt
    to each other's outputs rather than being trained independently.

SECTION 6 — TERMS TO KNOW IF THE PANEL ASKS
----------------------------------------------------------------

Overfitting     : Model memorises training data, performs poorly on new data.
                  Signs: high train accuracy, low val accuracy.
Underfitting    : Model is too simple, cannot learn the patterns.
                  Signs: low train and val accuracy.
Transfer Learning: Using a model pretrained on one task (ImageNet) and adapting
                  it to a new task (fire detection) by fine-tuning.
Fine-tuning     : Continuing to train a pretrained model on new data, usually
                  with a smaller learning rate to preserve existing knowledge.
Backbone        : The main feature extraction network (here: EfficientNet-B4).
                  Provides rich representations used by downstream components.
Patch tokens    : In ViT / our hybrid, the image is divided into fixed-size
                  patches, each linearly embedded into a token (vector).
Positional embedding : Added to each token so the Transformer knows the spatial
                  position of each patch (Transformers have no inherent order).
Dropout         : Randomly zeroes out a fraction (0.3 = 30%) of neurons during
                  training. Acts as regularisation to prevent overfitting.
Batch size      : Number of images processed together in one forward pass.
                  We use 32. Larger = faster training but needs more GPU memory.
Epoch           : One complete pass through the entire training dataset.
Checkpoint      : A saved copy of model weights at a specific epoch. We save
                  the best checkpoint (lowest val loss).
Softmax         : Converts raw output scores (logits) into probabilities that
                  sum to 1. Final layer of classifier.
Cross-entropy loss: Standard classification loss. Measures how far predicted
                  probabilities are from true labels.

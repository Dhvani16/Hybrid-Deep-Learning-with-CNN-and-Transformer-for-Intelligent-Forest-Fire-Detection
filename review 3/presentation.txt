SECTION 2 — CONCEPT EXPLANATIONS (what to say when asked)
----------------------------------------------------------------

► WHAT IS A CNN (Convolutional Neural Network)?
  A CNN is a type of neural network designed for images. It uses learnable
  filters (kernels) that slide across the image to detect local patterns —
  edges, textures, and colours. Each layer builds on the previous one,
  extracting increasingly abstract features: low-level edges in early layers,
  high-level flame shapes in deep layers. The key property is locality —
  each filter sees only a small patch at a time, making CNNs excellent at
  capturing local texture and colour gradients like fire.

► WHAT IS A VISION TRANSFORMER (ViT)?
  Originally designed for text (NLP), a Vision Transformer splits the input
  image into fixed-size patches (16×16 pixels) and uses Self-Attention to
  find relationships between ALL patches simultaneously — not just neighbours.
  This gives it global context: a smoke patch in one corner and a flame patch
  in another can jointly drive the prediction, regardless of distance.
  ViT requires more training data than CNNs because it has no built-in
  spatial inductive bias.

► WHAT IS SELF-ATTENTION?
  Self-Attention computes a relevance score between every pair of patches.
  High score means "these two regions are related." This allows the model
  to attend to the most important parts of the image, anywhere in the frame.
  The calculation: Q (query), K (key), V (value) vectors are computed for
  each token; attention(Q,K,V) = softmax(QK^T / sqrt(d)) × V.

► WHAT IS THE HYBRID MODEL?
  It combines EfficientNet-B4 (CNN backbone) for local fire texture extraction
  with a 4-layer Transformer encoder for global context reasoning.
  EfficientNet-B4 produces a 7×7×1792 feature map → 1×1 Conv projects to
  7×7×512 → flattened into 49 patch tokens + learnable CLS token → 4 Transformer
  encoder layers with 8-head attention → classifier reads CLS token output.
  This design needs far fewer Transformer layers (4 vs. 12 in ViT-B/16) because
  the CNN has already extracted semantically rich features.

► WHAT IS TWO-PHASE TRAINING?
  Phase 1 (8 epochs): EfficientNet-B4 backbone is frozen. Only the Transformer
  encoder and classifier head are trained at lr=5e-4. This stabilises new layers
  without corrupting the pretrained CNN weights.
  Phase 2 (20 epochs): All layers unfrozen and fine-tuned end-to-end.
  Backbone LR = 1e-5 (lower, to preserve ImageNet features);
  Transformer + head LR = 1e-4 (higher, to continue adapting).

► WHAT IS TRANSFER LEARNING?
  Using a model pretrained on a large general dataset (ImageNet) and adapting
  it to a new task (fire detection) on a small domain-specific dataset.
  Pretrained weights encode general visual features — edges, textures, shapes —
  that transfer effectively to fire/smoke recognition, enabling >98% accuracy
  with only 698 training images.

► WHAT IS GRAD-CAM?
  Gradient-weighted Class Activation Mapping uses gradients of the predicted
  class score with respect to the last convolutional feature map to produce
  a spatial heatmap. Bright regions = the model focused there. Applied to
  EfficientNet-B4's final conv block to confirm the model activates on
  flame cores and smoke boundaries — not irrelevant background.

► WHAT IS A CLS-TOKEN ATTENTION MAP?
  The CLS token's attention weights over all 49 spatial patches are extracted
  from the final Transformer encoder layer. Reshaped to 7×7, bicubically
  upsampled to 224×224, and overlaid on the image. Shows which regions the
  Transformer considered globally important — typically broader coverage
  including smoke areas beyond the immediate flame boundary.

► WHAT IS AUC-ROC?
  ROC curve plots True Positive Rate vs. False Positive Rate at every threshold.
  AUC = Area Under this Curve; summarises discrimination ability independently
  of threshold. AUC=1.000 = perfect (ViT); AUC=0.5 = random guessing.
  Our results: CNN=0.9984, ViT=1.0000, Hybrid=0.9975 — all excellent.

► WHAT IS CLASS-WEIGHTED LOSS?
  Dataset is imbalanced: 755 fire vs. 244 no-fire (3.09:1 ratio). Standard
  cross-entropy would bias the model toward always predicting "fire" (correct
  75% of the time). Class-weighted loss assigns higher penalty to no-fire
  mistakes, forcing the model to learn both classes correctly.
  Weights: w_fire ≈ 0.661, w_no-fire ≈ 2.053 (inverse frequency).

► WHAT IS CATASTROPHIC FORGETTING?
  When a pretrained model is trained with too high a learning rate on new data,
  the original pretrained weights are overwritten. This "forgets" the valuable
  ImageNet representations. Two-phase training prevents this by first freezing
  the backbone and using a very low backbone LR in Phase 2.

► WHAT IS SDG 13 AND SDG 15?
  SDG 13 (Climate Action): take urgent action to combat climate change.
  Forest fires release CO₂ and accelerate climate change. Early detection
  reduces megafire scale → reduces CO₂ emissions.
  SDG 15 (Life on Land): protect forests and biodiversity.
  Faster fire suppression → less habitat destruction → more biodiversity preserved.

► WHAT IS THE DEPLOYMENT RECOMMENDATION?
  Short-term: deploy ViT-B/16 (best current performance — zero missed fires).
  Medium-term: expand dataset to 5,000+ images; switch to Hybrid (superior
  architecture at scale — dual interpretability Grad-CAM + attention maps,
  fewer parameters than ViT, scalable to real-time drone inference).
  The phased plan is justified by empirical results: Hybrid underperforms
  now due to data scarcity, not a design flaw.

SECTION 5 — EXPECTED QUESTIONS & ANSWERS
----------------------------------------------------------------

Q1: Your hybrid model underperformed ViT and CNN. Does that mean it failed?
A:  No — this is the expected, well-documented behaviour of hybrid
    architectures on small datasets. CoAtNet (Dai et al. 2021) shows its
    advantage at ImageNet scale, not at 999 images. With 698 training images
    the Transformer encoder cannot fully train its 3 million extra parameters.
    On D-Fire (21,527 images), the Hybrid is expected to outperform both
    baselines. The 98.03% accuracy it did achieve is operationally viable
    and it closely tracks the CNN baseline with identical Recall.

Q2: Why deploy ViT if it needs more data — isn't it also large?
A:  ViT's strong performance comes from ImageNet-21K pretraining (14M images),
    not from the 698 training images. Its weights already encode rich visual
    representations; fine-tuning adapts them to fire imagery. With 86M
    parameters it is larger at inference, but on a cloud API this is not
    a constraint. For edge/UAV deployment the recommendation explicitly
    calls for knowledge distillation to a compact student model.

Q3: What is the significance of perfect Recall (100%) for ViT?
A:  Recall = of all actual fire images, how many did the model detect?
    100% means zero fires were missed on the 152-image test set.
    In fire safety, a missed detection (false negative) allows a small fire
    to become uncontrollable before anyone responds. ViT correctly flagged
    every single fire — this is the most critical metric for deployment.

Q4: What is the societal angle and why is it relevant to this technical study?
A:  Case study methodology requires analysing a problem from multiple angles
    — technical, operational, and societal — rather than just reporting
    accuracy numbers. The societal angle reveals that early fire detection
    reduces CO₂ emissions from megafires (SDG 13), protects biodiversity
    (SDG 15), and makes AI-based monitoring accessible to under-resourced
    forest regions worldwide. This grounds the technical choices — for example,
    maximising Recall over Precision, and using explainability tools — in
    real societal priorities, not just benchmark performance.

Q5: What does the phased deployment recommendation mean in practice?
A:  Phase 1 (months 1–2): deploy ViT-B/16 as a cloud inference API, integrate
    with existing monitoring dashboards, set threshold to 0.3 for safety-critical
    zones, begin collecting confirmed fire images. Phase 2 (months 3–6): label
    and aggregate new images to 5,000+. Phase 3 (months 7–9): retrain the Hybrid
    on the expanded dataset, run A/B evaluation against ViT, switch only if
    Hybrid matches ViT's Recall. Phase 4 (months 10–12): deploy knowledge-distilled
    edge model on drone hardware.

Q6: Why use Grad-CAM AND attention maps? Isn't one enough?
A:  They answer different questions. Grad-CAM (CNN path) identifies precise
    local flame boundary activations — "which pixels drove the prediction?"
    CLS attention (Transformer path) shows global scene context — "which
    regions was the model considering together?" A fire partially hidden by
    smoke may have weak local Grad-CAM activation but strong attention
    connecting the smoke region to a heat shimmer nearby. The dual explanation
    provides evidence that neither method alone can give.

Q7: What are the failure cases and what do they tell us?
A:  The Hybrid made 3 errors out of 152: 1 false negative (faint smoke with
    no visible flame) and 2 false positives (red/orange foliage, sunset).
    These failure modes are consistent across all three models, indicating
    the problem is at the dataset level — binary labels are insufficient.
    A "smoke only" class would let the model detect early-stage fires;
    a "natural fire-coloured" class would reduce false alarms from foliage.
    Multi-class annotation is the highest-impact next step.

Q8: How does transfer learning make 698 training images sufficient?
A:  EfficientNet-B4 was pretrained on 1.28 million ImageNet images; ViT-B/16
    on 14 million. These weights encode general visual features — edges,
    textures, colours — that apply directly to fire imagery. Fine-tuning
    on 698 images adapts the final layers to the fire/no-fire distinction
    without relearning low-level vision from scratch. Training from random
    initialisation would require tens of thousands of fire images.

Q9: What is the connection between this work and climate change?
A:  Wildfires release CO₂ from burned biomass. The 2019–20 Australian fires
    released an estimated 400 million tonnes of CO₂ — roughly equivalent
    to Australia's annual total emissions. Reducing fire spread area through
    earlier detection directly reduces these emissions. Additionally, fires
    destroy carbon-sink forests that are critical for long-term CO₂ sequestration.
    This study contributes to SDG 13 (Climate Action) by enabling faster
    detection that limits the scale of uncontrolled burning.

Q10: Can this system be deployed on a drone right now?
A:  Not the full ViT-B/16 model (86M parameters) in real-time — drone hardware
    like the NVIDIA Jetson Nano has ~4GB RAM and limited compute. However,
    knowledge distillation (identified as future work) can compress ViT into
    a lightweight student model capable of running at 10–30 fps on Jetson
    hardware. The Hybrid (22M parameters) is already significantly lighter
    and is the target for edge deployment after data scaling.

Q11: What is the review roadmap across all three reviews?
A:  Review 1 — problem identification, literature survey, architecture design,
    dataset selection, and initial prototype training.
    Review 2 — complete model training (all 3 models), evidence analysis
    (7 analyses: metrics, confusion matrix, ROC, training curves, Grad-CAM,
    attention maps, failure cases), and theoretical grounding (7 theories).
    Review 3 (this review) — final synthesis: problem + goal + approach +
    evidence + theory + recommendation + feasibility + impact + lessons.

Q12: Why is stratified splitting important for this dataset?
A:  The dataset has a 3.09:1 fire-to-no-fire imbalance. A random split could
    accidentally put most no-fire images in training or testing, skewing
    evaluation. Stratified splitting ensures every subset (train/val/test)
    has the same 75%/25% fire/no-fire ratio as the full dataset, so metrics
    are comparable and representative.

Q13: What would you do differently if you could redo this study?
A:  Three changes: (1) Start with D-Fire (21,527 images) as the primary
    dataset — it would likely show the Hybrid's advantage immediately.
    (2) Add multi-class labels from the start (fire/smoke/smouldering/no-fire)
    to address the primary failure mode. (3) Include temporal video clips
    (not just static images) so the model can leverage motion cues —
    smoke spreading over consecutive frames — for earlier detection of
    pre-flame smouldering.

Q14: How does the recommendation change if the priority is cost over performance?
A:  If inference cost is the primary constraint, deploy the CNN baseline
    (EfficientNet-B4, 19M parameters) rather than ViT (86M parameters).
    CNN achieved 98.68% accuracy with only 2 total errors on the test set
    and runs approximately 4.5× faster at inference than ViT. The trade-off
    is 1 missed fire per 114 fire images versus ViT's zero — a threshold
    decision that depends on the deployment risk tolerance.

Q15: What does the Reality Check table contribute to the presentation?
A:  It demonstrates that the recommendation is grounded in operational
    reality, not just technical optimism. A great model that cannot be
    deployed or managed in practice has no value. The table explicitly
    acknowledges what could go wrong (performance drift, false alarm fatigue)
    and provides mitigation steps — making this a responsible recommendation
    rather than just a best-case scenario.

SECTION 6 — TERMS TO KNOW IF THE PANEL ASKS
----------------------------------------------------------------

Overfitting        : Model memorises training data; poor on new data.
                     Sign: high train accuracy, low val accuracy.
Underfitting       : Model too simple to learn patterns.
                     Sign: low train and val accuracy.
Transfer Learning  : Adapting a pretrained model (ImageNet) to a new smaller
                     task by fine-tuning on domain-specific data.
Fine-tuning        : Continuing to train a pretrained model with a small LR
                     so prior knowledge is refined, not erased.
Backbone           : Main feature extractor — EfficientNet-B4 in the Hybrid.
Patch tokens       : Image divided into fixed-size patches, each embedded
                     into a vector (token) for the Transformer.
Positional embedding: Added to each token so the Transformer knows patch
                     spatial position (no inherent order in Transformers).
CLS token          : Learnable token prepended to the patch sequence.
                     After attention layers, it aggregates full scene context
                     and is fed to the classifier.
Dropout            : Randomly zeros out neurons during training (0.3 = 30%).
                     Regularisation to prevent overfitting.
Batch size         : Images processed together in one forward pass.
                     CNN=32, Hybrid/ViT=16 (larger model = less GPU memory).
Epoch              : One full pass through the entire training dataset.
Checkpoint         : Saved model weights at the epoch with best val accuracy.
Softmax            : Converts raw logits into probabilities summing to 1.
Cross-entropy loss : Standard classification loss; measures predicted
                     probability deviation from true labels.
AdamW              : Adam optimiser with decoupled weight decay (wd=0.01).
                     Better generalisation, especially for Transformers.
CosineAnnealingLR  : Learning rate decreases following a cosine curve —
                     fast early, slow and precise near convergence.
Gradient clipping  : Caps gradient norm (max=1.0) to prevent exploding
                     gradients during Transformer training.
Inductive bias     : Built-in assumptions about data structure.
                     CNN: local structure (translation equivariance).
                     Transformer: none — must learn spatial structure from data.
Data augmentation  : Random transforms (flip, rotate, colour jitter, blur)
                     applied at training time to increase data diversity.
Stratified split   : Train/val/test split preserving class proportions —
                     essential for imbalanced datasets.
Knowledge distillation: Compressing a large teacher model into a smaller
                     student model that mimics the teacher's predictions.
                     Used for edge/UAV deployment of large models like ViT.
Federated learning : Training a shared model across distributed data sources
                     without centralising the raw data — privacy-preserving.
Self-supervised pretraining: Learning representations from unlabelled images
                     (e.g., MAE masks patches; DINO uses self-distillation)
                     before fine-tuning on labelled fire data.
Precision          : TP / (TP + FP) — of all fire predictions, how many
                     were actually fire? Measures false alarm rate.
Recall             : TP / (TP + FN) — of all actual fires, how many were
                     detected? Critical for safety: missed fires are catastrophic.
F1-Score           : 2 × (Precision × Recall) / (Precision + Recall)
                     Balances both metrics; used when classes are imbalanced.
